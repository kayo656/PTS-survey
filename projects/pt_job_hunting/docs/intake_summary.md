# Intake Summary: PT学生の就職活動情報源に関する調査

## 1. 研究の背景と目的

## 2. データの構造
- **ファイル名**: `回答生データ.xlsx`
- **主要な変数 (7つの情報源)**:
  1. 学校からの紹介・教員・キャリアセンター
  2. 臨床実習先
  3. 友人・先輩・家族などの人的ネットワーク
  4. 病院・施設の公式採用ページ（公式HP）
  5. 就職情報サイト
  6. 就職説明会・合同説明会
  7. SNS（Instagram、X、YouTubeなど）

## 3. 数値変換ルール（リッカート尺度）
### 重要度 (Q3-Q9)
- 1: まったく重要でない
- 2: 重要ではない
- 3: あまり重要ではない
- 4: どちらかといえば重要
- 5: 重要
- 6: とても重要

### 利用度 (Q10-Q16)
- 1: まったく利用していない
- 2: ほとんど利用していない
- 3: あまり利用していない
- 4: やや利用した
- 5: よく利用した
- 6: 非常によく利用した

## 4. 解析対象者の抽出条件
1. 「同意する」と回答。
2. 「養成校の最終学年」である。
3. 主要アウトカム（重要度・利用度）に欠損がない。
