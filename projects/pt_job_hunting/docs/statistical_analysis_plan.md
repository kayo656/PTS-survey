# Statistical Analysis Plan (SAP)

## 1. 記述統計
- カテゴリカル変数（性別など）: 度数と割合 (%)
- 順序尺度（リッカート尺度）: 中央値 (Median) と 四分位範囲 (IQR)
- 可視化: 各情報源のスコア分布を示す棒グラフまたはボックスプロット

## 2. 主要解析（Friedman検定）
- **目的**: 同一対象者における7つの情報源間のスコア（重要度、利用度それぞれ）に統計学的な差があるかを検討する。
- **帰無仮説**: 7つの情報源のスコア分布は同一である。
- **有意水準**: 両側 5%

## 3. 事後検定 (Post-hoc)
- Friedman検定で有意差（p < 0.05）が認められた場合、Nemenyi検定（または対比較）を行い、具体的にどの情報源間に差があるかを特定する。

## 4. 欠損値の取り扱い
- 主要アウトカムに欠損がある対象者は、解析から除外する（リストワイズ除去）。
